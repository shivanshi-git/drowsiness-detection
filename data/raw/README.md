# ==============================================================================
# Raw Datasets Directory
# ==============================================================================

Place your massive datasets in the respective subfolders below:

1. **NTHU-DDD Dataset**:
   `data/raw/nthu_ddd/<Subject_ID>/<Scenario>/<Action_Video>.mp4` (e.g. `001/Night_Glasses/Slow_Blinking.mp4`)

2. **MRL Eye Dataset**:
   `data/raw/mrl_eye/<Subject_Folders>/*.png`

3. **YawDD Dataset**:
   `data/raw/yawdd/*.avi` or `*.mp4`

4. **Custom Image Dataset / Snapshots**:
   `data/raw/custom_images/*.jpg` or `*.png`

---
*Note: Training will automatically validate the directory and start immediately once you upload the files.*
