# Experiment: Baseline Vision Transformer (ViT-B/16)

## Overview
Standard ViT baseline operating on 2D frame inputs without low-light enhancement or optical flow motion stream.

## Results on NTHU-DDD
- Accuracy: 81.2%
- Macro F1: 78.6%
- Low-Light Night Scenario Degradation: -14.2% drop under infrared underexposure.
